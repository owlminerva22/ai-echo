# AI Echo — Where Thoughts Find Resonance

A poetic, calming Next.js website that explores the beautiful intersection of psychology and artificial intelligence.

## 🌟 Features

- **Poetic Design**: Calming, minimalist interface with gentle animations
- **Responsive Layout**: Perfect on all devices from mobile to desktop
- **Modern Tech Stack**: Built with Next.js 14, TypeScript, and Tailwind CSS
- **Interactive AI Chat**: Simulated AI conversation experience
- **Video Gallery**: Curated content exploring AI and psychology
- **About Section**: Deep dive into the philosophy behind AI Echo

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Navigate to the project directory:
```bash
cd ai-echo
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🎨 Design Philosophy

AI Echo embodies a poetic approach to web design, featuring:

- **Gentle Gradients**: Soft color transitions that evoke calm and contemplation
- **Floating Animations**: Subtle movements that bring the interface to life
- **Typography**: Clean, readable fonts that prioritize content
- **Whitespace**: Generous spacing that allows thoughts to breathe
- **Interactive Elements**: Hover effects and transitions that feel natural

## 🧠 Psychology & AI Integration

The website explores themes of:

- **Consciousness**: What makes human thought unique
- **Empathy**: How AI can understand and respond to human emotions
- **Resonance**: The beautiful space where human and artificial intelligence meet
- **Reflection**: Creating moments for deep thought and contemplation

## 🛠️ Built With

- **Next.js 14**: React framework with App Router
- **TypeScript**: Type-safe JavaScript
- **Tailwind CSS**: Utility-first CSS framework
- **Font Awesome**: Icons and visual elements
- **Google Fonts**: Inter font family for typography

## 📱 Responsive Design

The website is fully responsive and optimized for:

- Mobile devices (320px+)
